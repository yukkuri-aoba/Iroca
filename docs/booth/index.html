02 — Problem / 1280×720

「色を変えたいだけ」なのに。

  • PSD がない— 改変用データが付いていない。欲しいレイヤーもない。
  • レイヤーは統合済み— 一枚絵に焼き込まれて、パーツごとに分けられない。
  • アトラス化で団子— 最適化で複数パーツが 1 枚にまとまっている。

Camereo は、テクスチャ 1 枚から 塗り替える。

カラーゾーン
