04 — Color Zone / 1280×720

カラーゾーン

テクスチャ上のスポイトで変えたい色を選択して、
ターゲット色を設定するだけ。陰影も模様もそのまま残ります。
複数のゾーンを重ねれば、パーツごとに別の色へ変更できます。

スポイト操作のスクショ1600×900 / images/zone-eyedropper.png
05 — Exclusion Mask / 1280×720
ブラシ操作のスクショ1600×900 / images/mask-brush.png

変えたくない場所を
ブラシで保護

プレビュー上でブラシを塗るだけで、
その場所を色改変から保護できます。
全ゾーン共通とゾーン専用の 2 種類のマスクを使い分け可能。
Ctrl+Z の Undo にも対応。

06 — Preview & Preset / 1280×720

プレビューと
プリセット

変更前後の比較や差分表示に対応。
ピクセル単位まで拡大して確認できます。
設定をマスクごとプリセットとして保存でき、
JSON での書き出し・読み込みにも対応しています。

前後比較 / 差分のスクショ1600×900 / images/preview-diff.png
07 — OkLab / 1280×720

OkLab ベースの再着色エンジン

知覚色空間 OkLab で再着色するため、
色相を変えても明度と陰影が自然に残ります。
HSV ベースの変換で起きがちな中間色の濁りを抑えます。
