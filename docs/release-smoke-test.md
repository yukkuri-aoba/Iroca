# リリース前の Unity 実地確認

Code/UI と AI 導入まわり（Sentis 導入・モデル取得・再起動の案内）は、ハーネスにも視覚ゲートにも入っていない。
リリース前に 1 回、**新しく作った VRChat アバタープロジェクト**でこの表を上から通す（目安 30〜60 分）。
AI のモデル（`%LOCALAPPDATA%\Iroca\Models`）が既にあると初回ダウンロードを確かめられないので、
確認の前にフォルダ名を変えて退避しておく（終わったら戻す）。

## 準備: 未公開の版を入れる

確かめる版はまだ listing に無いので、手元で作った zip を直接展開する。

```powershell
# リポジトリで（作業ツリーを汚さないよう一時 worktree で作る）
git worktree add --detach "$env:TEMP\iroca-smoke" HEAD
cd "$env:TEMP\iroca-smoke"; .\scripts\Build-VpmPackage.ps1 -Version <VERSION>
# Unity を閉じた状態で、zip の中身を <プロジェクト>\Packages\com.yukkuri-aoba.iroca\ へ展開する
# 終わったら: git worktree remove --force "$env:TEMP\iroca-smoke"
```

CHANGELOG.md に `## [<VERSION>]` 節が無いと Build-VpmPackage.ps1 は止まる。`## [Unreleased]` のままなら、先に見出しを `## [<VERSION>] - <日付>` にしておく。

非破壊の確認（21〜23）には NDMF が要る。VCC でいろかのリポジトリ `https://yukkuri-aoba.github.io/Iroca/index.json`（NDMF も載っている）か NDMF のリポジトリ `https://vpm.nadena.dev/vpm.json` を追加し、プロジェクトへ「Non-Destructive Modular Framework」を入れておく（31・33 は NDMF の無い別のプロジェクト、35 は NDMF の版を変えたプロジェクトで行う）。
