# リリース前の Unity 実地確認

Code/UI と AI 導入まわり（Sentis 導入・モデル取得・再起動の案内）は、ハーネスにも視覚ゲートにも入っていない。
リリース前に 1 回、**新しく作った VRChat アバタープロジェクト**でこの表を上から通す（目安 30〜60 分）。
AI のモデル（`%LOCALAPPDATA%\Iroca\Models`）が既にあると初回ダウンロードを確かめられないので、
確認の前にフォルダ名を変えて退避しておく（終わったら戻す）。

## 準備: 未公開の版を入れる

listing は公開前なので、手元で作った zip を直接展開する。

```powershell
# リポジトリで（作業ツリーを汚さないよう一時 worktree で作る）
git worktree add --detach "$env:TEMP\iroca-smoke" HEAD
cd "$env:TEMP\iroca-smoke"; .\scripts\Build-VpmPackage.ps1 -Version 0.2.0
# Unity を閉じた状態で、zip の中身を <プロジェクト>\Packages\com.yukkuri-aoba.iroca\ へ展開する
# 終わったら: git worktree remove --force "$env:TEMP\iroca-smoke"
```

## 確認項目

| # | 操作 | 期待する結果 |
|---|---|---|
| 1 | プロジェクトを開く | Console にエラーも警告も出ない（いろか由来の CS8632 などが無い） |
| 2 | メニューを見る | `Tools > いろか` がある。`Window > Iroca` など開発用のメニューは無い |
| 3 | `Tools > いろか` を開く | 上部に「Unity Sentis の導入が必要です」の帯。テクスチャ未設定の案内が出る |
| 4 | テクスチャを入れ、ゾーン追加 →「スポイト」で色を取る | プレビューがすぐ変わる（許容範囲 0.20 で始まる） |
| 5 | 「自動調整」を押す（Sentis 未導入） | 中止され、導入の案内が出る。Editor が固まらない |
| 6 | 帯の「AI 機能を有効化（Sentis を導入）」 | Sentis 2.1.3 が入り、再コンパイル後に「モデルをダウンロード」の帯に変わる |
| 7 | 「モデルをダウンロード」 | 進捗が出て完了し、帯が消える。「中止」で止まることも 1 回試す |
| 8 | 再起動を勧められたら「Unity を再起動」 | 再起動後もゾーンとマスクが残っている |
| 9 | パーツを右クリック →「AI 提案: この領域を除外」 | 数秒以内に領域がマスクへ足される（初回は解析待ちの進捗が出る） |
| 10 | Ctrl+Z | 直前に足した領域だけが消える |
| 11 | 「マスクを編集...」の AI 提案欄で粒度を「細かい」「大きい」に変えて右クリック | 取れる範囲が変わる |
| 12 | 右クリックの「追加先を変える」でゾーンを選び「AI 提案: この領域を含める」/ マスク編集で「含める」をブラシで塗る | 緑で重ね表示され、その部分が色替えされる |
| 13 | アバターをシーンに置いた状態で、衣装のテクスチャを開いてマスク欄の「メッシュ」を見る | アバター（か Prefab）の名前と「自動（シーンから）: メッシュ N 個」が出る。状態の行にカーソルを置くとメッシュ名の一覧 |
| 14 | 「UV の島をプレビューに表示」をオン → 拡大・スクロール | 黄色い輪郭線が出る。線はプレビュー枠の外へはみ出さない |
| 15 | 島の上を右クリック →「パーツ: この島を除外」→ Ctrl+Z | 輪郭で囲まれた島がマスクへ入り、Ctrl+Z 1 回で戻る |
| 16 | 「メッシュ」欄へ FBX をドラッグ → 欄を選んで Delete | 「指定: メッシュ N 個」になり、Delete で自動に戻る |
| 17 | メッシュの無いテクスチャ（どのマテリアルも使っていない画像）を開いて右クリック | 「メッシュ」は「見つかりません」、右クリックのパーツ項目は無効表示。色の処理は普段どおり |
| 18 | スポイトで取り直して「自動調整」 | 解析の進捗と中止ボタンが出て、パーツの暗部から明部まで色が変わる |
| 19 | 「自動調整」中に「中止」 | 解析が止まり、設定は変わらない |
| 20 | 「適用して保存」（新規保存）→「Project で表示」 | 新しい PNG ができて選択される。元のテクスチャは変わらない |
| 21 | プリセットをプロジェクト・ユーザー共通それぞれに保存して読み込む | 設定とマスクが戻る |
| 22 | 言語を English に切り替え、3〜19 のうち帯・右クリックメニュー・メッシュ欄・自動調整を見る | 日本語が混じらない |
| 23 | English のままモデルフォルダを退避してオフラインで「Download models」 | 英語のエラーが出て、「Open model folder」への案内がある |
| 24 | モデルファイルの片方を 0 バイトのファイルに置き換えて Unity を再起動 → AI 提案 | エラーのあとに「モデルをダウンロード」（取り直し）の導線が出て、取り直すと直る |

問題が出たら、Console のログと操作手順を控えて直す（開発ホストでは Debug の「再現データを書き出す...」で回帰ケースにできる）。
全部通ったら `docs/RELEASING.md` の該当チェックを付ける。
