カラーゾーンの設定

ゾーンは「この色を、この色に変える」1 つぶんの設定です。2 色目からは「スポイトで別の色を追加」でゾーンを足します（「+ 空のゾーン」は、色を決めずにゾーンだけを作ります）。

2 色目を足す: 「スポイトで別の色を追加」→ 明るいグレーの部分をクリック → 変更先カラーを濃いグレーに → 自動調整（待ち時間は 3 倍速）

基本の項目（常に表示）

ゾーン 1 枚ぶんの基本の項目（自動調整のあと）

サンプルカラー

色替え対象の基準色です。この色に近いピクセルが対象になります。右の「スポイト」ボタンで取ると、クリック位置も「自動調整」の手がかりとして記憶します。

自動調整

テクスチャを解析して、許容範囲・彩度制限などをまとめて決めます。スポイトした位置に AI マスク提案（MobileSAM）をかけ、そのパーツの暗部からハイライトまでを取りこぼさないように導出します。スポイトで色を取り、変更先カラーを決めてから押すのが最も効果的です（模様保持は、元の色と変更先の明るさの差から決めます）。

  • 元テクスチャが未設定、画素を取り出せない、サンプルカラーが未指定（白のまま）のときは押せません。
  • AI が未導入のときは導入の案内が出ます（→「AI マスク提案」の「必要なもの」）。準備中のときは終わるまで待ちます（進捗バーと「キャンセル」ボタンが出ます）。
  • カラーピッカーで色を指定したゾーンは位置がないため、AI 提案なしで解析します（ゾーンに「スポイト位置がありません」と出ます）。
  • 自分で値を変えているときだけ、上書きの確認が出ます。

許容範囲

色の一致をどこまで許すかです（0.0〜1.0）。低いほど厳密（選択が狭い）、高いほど広く拾います（ノイズも増えます）。目安は 0.15〜0.40 です。新しいゾーンは 0.20 で始まります。

変更先カラー

変えたあとの色です。

模様保持

元の明度をどれだけ残すかです。0 に近いほどベタ塗り風、1 に近いほど元の柄をそのまま残します（既定 1.0）。

出力彩度

色替え後の鮮やかさです（既定 1.0）。純赤など彩度 100% の色は明暗が潰れてベタ塗りに見えがちです。0.7〜0.9 に下げると、色相は保ったまま陰影が戻ります。

詳細の項目（「詳細設定」を開くと表示）

上から処理の走る順（選択の範囲 → ハイライト → 暗部・無彩色 → 色の写り方）に並んでいます。触りすぎたときは、ゾーン末尾の「詳細を既定値に戻す」で初期化できます。詳細の項目と、基本の項目の模様保持・出力彩度が既定値に戻ります（色・許容範囲・名前・連続領域モード・シードは残ります）。

詳細設定（製品の既定値）

連続領域モード（既定 ON）

色が一致した領域のうち、確信度の高い芯を含む「つながった塊」だけに色替えを絞ります。離れた同色パーツや背景へのにじみが自動で外れます。既定は自動で、シードは要りません。

特定の塊だけ残したいときはシードを置きます。「シード（任意）」行の「指定」を押してからプレビューをクリックするか、プレビューを Shift+クリックします（詳細設定を閉じていても使えます。置いた位置はプレビューに十字で出ます）。「自動へ」で解除します。

エッジ柔らかさ（既定 0）

0 で硬いエッジ、上げるとアンチエイリアス境界をなめらかに拾います。ぼかしのあるテクスチャ向けです。

彩度制限（影の厳しさ）（既定 0.50）

薄い影や AO（暗い陰り）をどこまで拾うかです。上げるとはみ出しが減り、境界に色のドットが残りやすくなります。下げるとその逆です。

彩度ガード（無彩色よけ）（既定 0）

鮮やかな色を選んだとき、白・黒・灰色が混ざるのを防ぎます。許容範囲を大きく上げるときに使います。選んだ色が灰色寄りなら自動で無効になります。

穴埋めの余白（既定 0）

選択に囲まれた小さな穴を埋めるとき、許容範囲をこの割合だけ広げて判定します。布の明るい面のように、色が許容範囲の境目をまたぐ所で元の色が点々と残るのを防ぎます。囲まれていない画素には広がりません。AI 提案ありの自動調整が設定します。許容範囲を手で広く取ったときに上げると、別の部位が塊で塗られることがあります。初期設定（境界クリーンアップ ON・エッジぼかし 0）では、色のあるパーツには効きません。

ハイライト補助（既定 ON）

高明度・低彩度のハイライト（鏡面反射・光沢）もマッチさせ、光沢素材の塗り残しを防ぎます。ON のときに効く「ハイライト帯の拡張」（既定 ON。ハイライト補助が OFF の間は灰色で触れません）は、本体につながった描き込みハイライトまで範囲を広げます。

ハイライト白寄せ合成（既定 OFF）

開発者向けの項目です。ふだんは表示されず、ウィンドウのタブの「⋮」メニューの「開発者向けの設定を表示」で出ます（プリセットなどで既定から変わっているゾーンでは、常に表示されます）。

明部を白へ寄せて、鏡面ハイライトの白い反射を表現します。光沢・プラスチック向けです。ON のときに効く「ハイライト自動補正」（既定 OFF。白寄せ合成が OFF の間は灰色で触れません）は、パーツの地色を自動で見つけて白寄せを全体に効かせます。髪など細い房の多いテクスチャでは広がりすぎることがあるので、その場合は OFF にします。

暗部・無彩色

「暗部の明度下限」「別パーツの彩度上限」「別パーツの色相幅」は、近い色の別パーツを、離れたかたまりごと選択から外すための項目です。AI 提案ありの自動調整が、クリックしたパーツに実在する暗さ・鮮やかさ・色相の広がりから導きます。連続領域モードでのみ効き、スポイトでクリックした場所を含むかたまりは外しません。

設定説明既定
暗部の彩度低下この明度より暗いピクセルの彩度を落とす。下げると暗い色も鮮やかに染まる0.35
暗部に含める最低彩度暗いピクセルを影として拾うのに必要な最低彩度。純粋なグレー・黒の色付けを防ぐ0.05
暗部の明度下限この明度以上のピクセルが半分に満たない離れた領域を、同じ素材の陰影とみなさず外す。同じ色相で暗いだけの別パーツ（上衣に対する暗いジャケットなど）の巻き込みを防ぐ。0 = 無効0
別パーツの彩度上限色が近くても、より鮮やかな離れた領域を別のパーツとみなして外す。0 = 無効0
別パーツの色相幅色相が少しずれた離れた領域を別のパーツとみなして外す。彩度の低いピクセルは判定に使わない。0 = 無効0
無彩色とみなす彩度サンプルの彩度がこの値以下なら、色相を無視して無彩色（白・グレー・黒）として抽出する0.05
無彩色の彩度上限白・グレー・黒をスポイトしたとき、これより色づいた離れた領域を「染められた別素材」とみなして外す。0 = 自動（サンプル彩度の 3 倍、最低 0.04）。白い布の陰が青みがかっているときは上げる0

基準色の自動補正（既定 ON）

「色の写り方」の項目です。影やツヤをスポイトしても、パーツの地色が変更先の色に合うよう基準を補正します。地色がはっきりしたパーツではいちばん多い色を合わせ、それより明るい面は変更先の色より明るく、影は暗く塗ります。なだらかなグラデーションのパーツと、肌・白など地色が明るいパーツでは明るい面を合わせます。クリックした画素そのものを変更先の色にしたいときは OFF にします。選択範囲は変わりません。

マッチング距離の重み

色の距離式そのものの係数です。ふつうは触りません。開発者向けの項目で、ふだんは表示されず、ウィンドウのタブの「⋮」メニューの「開発者向けの設定を表示」で出ます（プリセットなどで既定から変わっているゾーンでは、常に表示されます）。

設定説明既定
明度重み高いほど明度差に敏感（別素材を分離しやすい）。低いほど同じ素材の影・ハイライトを吸収する1.0
彩度距離重み高いほど彩度差に敏感0.15
彩度ランプスケール大きいほど彩度閾値付近でなだらかにフェードする0.10

これらの値もプリセットに保存されます。

ゾーンの優先度（並び順）

ゾーンが重なる部分には、リストで上にあるゾーンだけが適用されます。各ゾーン左の ☰ をドラッグして並べ替えます。
