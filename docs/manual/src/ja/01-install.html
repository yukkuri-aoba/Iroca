インストール

前提条件

  • Unity 2022.3（2022.3.22f1・Windows で検証しています。自動調整と AI マスク提案に使う Unity Sentis 2.1.3 は 2022.3.11f1 以降が必要です）
  • PNG / JPG のテクスチャはそのまま使えます
  • PSD・TGA・EXR などは Read/Write Enabled が必要です。無効のときはウィンドウに警告が出て、「Read/Write を有効にする」ボタンで有効にできます（Undo できないため確認が出ます）

手順

  1. GitHub Releases から Iroca_v<バージョン>.zip をダウンロードして展開します（中身はインストーラ Iroca_Installer.unitypackage と README.txt・LICENSE.txt です。同じ欄の com.yukkuri-aoba.iroca-<バージョン>.zip は VCC / ALCOM が取得するパッケージ本体なので、ダウンロードする必要はありません）。
  2. Iroca_Installer.unitypackage を Unity のプロジェクトウィンドウへドラッグ＆ドロップし、「Import」を押します。
  3. 確認ダイアログで「Install」を押すと、いろかの最新版がダウンロードされ、プロジェクトの Packages に入ります（インターネット接続が必要です。インストーラ自体は自動で消えます）。
  4. メニューの Tools > いろか でウィンドウを開きます。

VCC / ALCOM を使っているなら、リポジトリ https://yukkuri-aoba.github.io/Iroca/index.json を追加して、プロジェクトの管理画面から「いろか」と「Non-Destructive Modular Framework」（NDMF）を追加する方法でも導入できます。NDMF もこのリポジトリに載っています。新しい版が出たら、VCC / ALCOM から更新するか、インストーラをもう一度読み込みます。

VRChat SDK の無いプロジェクトに入れる

インストーラは VRChat のプロジェクト向けです。一緒に入れる NDMF は VRChat SDK を前提にしているため、SDK の無いプロジェクトではコンパイルエラーになります。そのときはインストーラを使わず、いろかだけを入れます（画像の書き出しが使えます。非破壊の色替えは使えません）。

  1. GitHub Releases から com.yukkuri-aoba.iroca-<バージョン>.zip をダウンロードします。
  2. プロジェクトの Packages フォルダの中に com.yukkuri-aoba.iroca フォルダを作り、zip の中身をそこへ展開します（そのフォルダのすぐ下に package.json があるように）。
  3. Unity に戻ると読み込まれます。メニューの Tools > いろか でウィンドウを開きます。

新しい版にするときは、フォルダの中身を新しい zip の中身に入れ替えます。

このマニュアルは、いろかウィンドウ上部の「マニュアル」でいつでも開けます。

旧版（0.1.0、旧名 VRC Avatar Color Changer）を使っていた場合は、Assets/VACC フォルダを削除してください。いろかとは別物として入るため、残すと旧版も動いたままになります。プロジェクト内に保存したプリセットが必要なら、削除の前にバックアップしてください。
