プリセット

カラーゾーンと加工設定を保存・読み込みできます。

プリセット。保存先はプロジェクト内と全プロジェクト共通の 2 つ

保存と読み込み

「プリセット」セクションで名前を入れ、「保存先」を選んで「保存」を押します。一覧の「読込」で読み込み、「×」で削除します。

  • プロジェクト内: Assets フォルダ内に保存します。Git などでチームと共有できます。
  • 全プロジェクト共通: OS のユーザーフォルダに保存します。この端末のすべてのプロジェクトで使えます。

一覧は「このプロジェクト」と「全プロジェクト共通」に分かれ、両方の場所のプリセットが出ます。いま開いているテクスチャで作ったプリセットには「このテクスチャ」と出て、それぞれの一覧の先頭に並びます。マスクも同じ場所にそのまま合います。

カラーゾーンが 1 つも無いときは、保存したプリセットがあり、ウィンドウの高さに収まるなら、「プリセット」セクションが開いた状態で出ます。ゾーンを作ると、元の開閉に戻ります。

マスクの保存・読み込み

「詳細（マスク・JSON 入出力）」の「マスクも保存する」が ON（既定）なら、塗ってあるマスクもプリセットに入ります。「マスクも読み込む」を OFF にすると、読み込み時にマスクだけ無視します。

JSON の書き出し・読み込み

同じ欄の「JSON エクスポート」「JSON インポート」で、設定をファイルとしてやり取りできます。
