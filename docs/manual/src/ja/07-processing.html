加工設定

全ゾーン共通の、エッジとノイズの処理と、編集する解像度の設定です。既定値のままで使えるので、最初は畳まれています。

加工設定と、その詳細設定（製品の既定値）

エッジぼかし

選択境界をぼかして、エッジの色をなじませます（0〜5）。既定は 0（オフ）で、ふだんは 0 のままにしてください。縁の混ざった色は、下の境界クリーンアップが混ざっている割合だけ色替えするので、ぼかさなくても縁はなじみます。0 より大きくすると、この塗り方が使われなくなります。

縁のドット回収

アンチエイリアス境界に残るドットを回収するパス数です。0 でオフ、3 が既定、4〜5 で強めです。初期設定（下の境界クリーンアップ ON・エッジぼかし 0）では、色のあるパーツには効きません。縁は境界クリーンアップが塗ります。白・黒・灰のパーツと、境界クリーンアップ OFF またはエッジぼかしを使うときに効きます。

境界クリーンアップ

境界の混ざった色（アンチエイリアス・にじみ）を、パーツの色が混ざっている割合だけ色替えします。縁に元の色が点々と残る、許容範囲を上げるとパーツの周りに輪（ゴースト）が出る、境界が薄汚れた中間色（ハロー）になる、を防ぎます。既定は ON で、通常はそのままで構いません。

元の解像度で編集

オフ（既定）のときは、プレビュー・AI 提案・自動調整と「アバターに非破壊で登録」のテクスチャを、インポート設定の Max Size の大きさで処理します。ゲームに出るのもこの大きさなので、見た目はほとんど変わりません。元の画像が Max Size より大きいとき（8192×8192 の画像を Max Size 2048 で使うなど）に、メモリを大きく減らせます。

オンにすると、元の画像の解像度で処理します。拡大表示で元の画像の細部まで確かめられますが、大きい画像ではメモリを多く使います（8192×8192 で 6 GB ほど）。書き出し（「適用して保存」）は、どちらでも元の画像の解像度で行います。この設定はこの PC のいろか全体に効き、ほかのプロジェクトの再生・アップロードで作る色替えにも効きます（プリセットには保存しません）。

詳細設定（折りたたみ）

通常は既定のままで構いません。
