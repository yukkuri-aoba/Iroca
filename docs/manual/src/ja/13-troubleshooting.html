困ったとき

範囲の問題は、まず右クリックで直せないか試してください（→「右クリックで直す」）。数値を動かすのは、そのあとで構いません。AI の動作については「AI マスク提案」の「うまく動かないとき」にまとめています。

ほかの場所まで同じ色に変わった

いろかは、選んだ色と同じ色の場所をテクスチャ全体で変えます。一か所だけ変えたいときは、その場所を右クリックして「この部分だけ塗る」を選びます。同じ色の別パーツを外したいときは、そこを右クリックして「ここは塗らない」を選びます。

アトラスに並んだ同じ色の別パーツ（パンツとブーツなど）は、色では分けられません。テクスチャを使うメッシュが見つかっていれば、右クリックの「メッシュの形で」→「ここは塗らない」で島ごとに外せます。

色の範囲そのものが広すぎるときは、許容範囲を 0.05〜0.15 まで下げ、サンプルカラーをより限定的な色で取り直します。離れた領域まで変わるときは、詳細設定の連続領域モードが ON か確かめ、残したい塊にシードを置きます（→「連続領域モード」）。

塗れていない所がある

まだなら「自動調整」を押します（ハイライトの芯などを拾えるようになります）。それでも残る所は、右クリックして「ここも塗る」を選びます。白い服など、色の判定で拾いきれない部分は「ここも塗る」で足すのが早道です。

パーツの中の淡い部分（金属の反射・淡い縁取りなど）が元の色のまま残るときは、許容範囲ではなく彩度制限を下げます。許容範囲を上げても、色の薄い部分は選ばれません。

隣のパーツへ色がはみ出す

はみ出した所を右クリックして「ここは塗らない」を選びます。全体に少しずつはみ出すときは、彩度制限を 0.8〜0.95 に上げ、許容範囲を狭めます。白・黒・灰を巻き込んでいるなら彩度ガードを上げます。エッジ柔らかさを 0.0〜0.5 で調整するのも有効です。

図形の周りに薄い色やドットが残る

アンチエイリアスやぼかしで薄くなった縁まで色替えに巻き込まれ、図形の周りに薄い色の点が残っています。次の順に試してください。

  1. 彩度制限（影の厳しさ）を 0.7〜0.9 に上げる
  2. 許容範囲を狭める
  3. 詳細設定の連続領域モードが ON か確かめ、残したい塊にシードを置く
  4. 残った部分を「ここは塗らない」か除外マスクで保護する

境界に細かいノイズが残る

まず加工設定の境界クリーンアップが ON で、エッジぼかしが 0 か確かめます（エッジぼかしを上げると、境界クリーンアップの縁の塗り方が使われなくなります）。それでも残るなら、彩度制限を 0.1〜0.4 に下げます（そのぶんはみ出しやすくなります）。あわせてエッジ柔らかさを 0.3〜0.7 で試します。白・黒・灰のパーツでは縁のドット回収を既定の 3 から 4〜5 に上げるのも効きます。

境界がギザギザしている・硬い

まず加工設定の境界クリーンアップが ON で、エッジぼかしが 0 か確かめます。足りなければエッジ柔らかさを 0.3〜0.7 に上げ、彩度制限を 0.3〜0.45 まで少し下げます。元の画像の縁がもともとギザギザしているときは、色替えの後もそのままです（いろかは縁をなめらかにしません）。

仕上がりがベタ塗りになる

出力彩度を 0.7〜0.9 に下げます。模様を残したいときは模様保持を上げます。

黒い色に変更できない

黒は明度の情報がほとんどなく、模様保持が効きにくくなります。模様保持を 0〜0.3、エッジ柔らかさを 0 にします。保護したい部分は先に「ここは塗らない」か除外マスクで囲っておきます。

「いろか: アップロードを止めました」と出る

NDMF が入っていない、または対応していない版なので、「Iroca Recolor」の付いたアバターを色替えできません。色替えされないまま上がらないよう、いろかがアップロードを止めています。メッセージにある直し方（NDMF を追加する・NDMF を新しくする・いろかを新しくする）に従ってから、アップロードし直してください。色替えせずに上げたいときは、アバターから「Iroca Recolor」を外します（→「アバターに反映（NDMF）」）。

再生のたびに NDMF Console が開く

「いろか: 色替えするマテリアルが見つかりません」と出ているときは、「Iroca Recolor」の範囲（付けたオブジェクトとその子）に、レシピの元テクスチャを使うマテリアルがありません。衣装を差し替えたときなどに起き、再生のたびに NDMF Console が開きます。色替えを続けるなら、「Iroca Recolor」を衣装やアバターの親に置きます。マテリアルが書き出した _recolored.png を使っているなら、元のテクスチャに戻します。要らなくなったレシピなら、「Iroca Recolor」のインスペクタの「レシピ」の一覧から外します。

「他のツールに生成されたと思われるテクスチャアセットに、ミップストリーミングがオフになっています」と出て、名前の末尾が「(Iroca)」のテクスチャが並んでいるときは、元テクスチャのミップストリーミングがオフです。いろかは元テクスチャの取り込み設定を引き継ぐので、元テクスチャの Inspector で「Mip Streaming」をオンにして「Apply」を押すと出なくなります（VRChat SDK もアップロードのときに同じ設定を求めます）。

再生・アップロードの開始が数秒遅れる

いろかのウィンドウで色を変えた直後の最初の再生・アップロードは、色替えをその場で作るので数秒かかります。2 回目からはキャッシュを使うので速くなります（→「アバターに反映（NDMF）」の注意）。

「大きい画像です」と出る

8192×8192 より大きい画像を開くと、使うメモリの目安とこの PC のメモリの量が出ます。編集をインポート設定の Max Size の大きさで行っているときは、書き出し（「適用して保存」）のときだけメモリを多く使うので、書き出す前にほかのアプリを閉じてください。元の解像度で処理しているとき（Max Size が元の画像以上、または「元の解像度で編集」がオン）は、編集中からメモリを多く使います。足りないときは「元の解像度で編集」をオフにして、Max Size を下げます（→「元の解像度で編集」）。「閉じる」を押すと、そのテクスチャでは Unity を閉じるまで出ません。

Scene でモデルをクリックしても場所が出ない

  • いろかのウィンドウを閉じていると反応しません（タブの裏に隠れているだけなら反応します）
  • プレビューの上に「ここは『○○』のテクスチャです」と出ていれば、クリックした部分は別のテクスチャを使っています。「開く」で切り替えます
  • 何も出ないときは、マテリアルのメインテクスチャ（_MainTex など）が開いているテクスチャではない可能性があります。いろかで書き出した _recolored のテクスチャを使っているマテリアルは、元のテクスチャと同じものとして扱います

ウィンドウの大きさを変えると Unity が落ちる

ウィンドウの端をドラッグしている途中で Unity が終了し、ログ（%LOCALAPPDATA%\Unity\Editor\Editor.log。落ちた後に Unity を開き直したなら Editor-prev.log）に 0x887a0005 や Failed to present D3D11 swapchain due to device reset/removed が出ていれば、Unity（Direct3D 11）と GPU ドライバの組み合わせの問題です。いろか以外のウィンドウでも起きますが、いろかのプレビューは描画が多いので、開いているときに起きやすくなります。Intel の内蔵 GPU（Arc B390）で確認しています。

Unity Hub のプロジェクト一覧で、そのプロジェクトの行の右端のメニューから「コマンドライン引数を追加」を選び、-force-d3d12 と入れて開き直すと、Unity が Direct3D 12 で動きます。確認した環境では、これで落ちなくなりました（タイトルバーに <DX12> と出ます。戻すときは引数を消します）。GPU ドライバの更新で直ることもあります。

いろかの編集内容は手を止めて 2 秒ほどで自動保存しているので、落ちても失うのは直前の数秒ぶんだけです。
