## 説明文

最初のブロックを「商品紹介文」欄に貼る。残りは「＋ 段落」で足し、見出しを「見出しテキスト」、本文を「本文テキスト」に入れる。

- BOOTH に一言説明の欄は無い。商品紹介文の冒頭約 300 字が、SNS などに出るカードの説明文になる。
- 更新履歴の「（公開日）」は公開時に埋める。
- 段落を使わず 1 つの欄にまとめる場合は、各ブロックの前に「■使い方」のように見出しを置き、空行で区切る。
- 本文は和文と英数字の間を空けない。括弧は全角。

### 商品紹介文

```
いろかは、VRChatアバターや衣装のテクスチャの色をUnity上で変えるためのエディタ拡張です。無料でお使いいただけます。
画像編集ソフトを使わずに好きな色の服を着るのが、実は難しかったので作りました。1枚に複数のパーツがまとまったテクスチャや、模様の入ったパーツでも、狙った色だけをきれいに変えられるようにしています。

スポイトで変えたい色をクリックして変更先の色を選び、「自動調整」を押すと、影の所も光っている所も、同じ素材の範囲がまとめて変わります。陰影はそのまま残り、範囲を自分で探して合わせる必要はありません。PSDが付いていないテクスチャにも使えます。
色替えは元のテクスチャを書き換えずにアバターへ反映できるので、あとから何度でも色を直せます。

まだベータ版です。不具合やご要望は、ページ下部の連絡先までお寄せください。

使い方はオンラインマニュアルにまとめています。
https://yukkuri-aoba.github.io/Iroca/manual/
```

### 段落：使い方

```
1. いろかのウィンドウを開き、色を変えたいテクスチャを「テクスチャ」欄へドラッグします
2. 「スポイトで変えたい色を選ぶ」を押して、プレビュー上の変えたい色をクリックします
3. 「変更先カラー」で新しい色を選びます
4. 「自動調整」を押すと、影からハイライトまでが入るように範囲を合わせます（押さなくても色は変わります）
5. 「アバターに非破壊で登録」を押せば完了です。画像（PNG）として書き出すこともできます

はみ出したところや塗り残しは、プレビューを右クリックして「ここは塗らない」「ここも塗る」で直せます。細かいところはブラシでも塗れます。
同じ色がほかの場所にもあって、一か所だけ変えたいときは「この部分だけ塗る」を選びます。
```

### 段落：主な機能

```
・色は複数指定でき、パーツごとに別の色にできます
・右クリックでは、クリックした場所がどこまでのパーツかをAI（MobileSAM）が見分けます。AIの処理もPCの中だけで行うので、テクスチャが外部に送られることはありません
・テクスチャを使うメッシュが見つかれば、メッシュの形（UVの島）でも範囲を指定できます。色では分けられない、同じ色の別パーツも分けられます
・アバターへの登録は、NDMFを使った非破壊方式です。元のテクスチャとマテリアルはそのままで、再生やアップロードのときだけ色を変えたテクスチャに差し替わります。再生しなくても、シーン上のアバターで仕上がりを確認できます
・どのテクスチャを開けばいいか分からないときは、いろかのウィンドウを開いたままSceneでモデルの変えたい所をクリックすると開けます
・設定はプリセットとして保存でき、JSONで別のプロジェクトにも持っていけます
```

### 段落：苦手なテクスチャ

```
似た色があちこちにあるテクスチャや、グラデーションや強い光沢があるテクスチャは、一度では思いどおりの範囲にならないことがあります。右クリックの「ここも塗る」「ここは塗らない」やブラシで直してください。マニュアルの「トラブルシューティング」にも対処法を載せています。
```

### 段落：動作環境

```
・Unity 2022.3（2022.3.22f1・Windowsで動作を確認しています）
・入力：PNG／JPG（PSDやTGAなども、Read/Writeを有効にすれば使えます）
・出力：PNG
・4096×4096までのテクスチャで確認しています
・AIを使う機能（自動調整と、右クリックでの範囲の見分け）には、Unity Sentis 2.1.3（Unity 2022.3.11f1以降）とAIモデル（約44MB）が必要です。どちらもウィンドウ上部の案内から導入できます
・アバターへの登録にはNDMF 1.8以上を使います。インストーラで導入した場合は一緒に入ります。NDMFがなくても、画像（PNG）の書き出しは使えます
```

### 段落：導入方法

```
1. 「Iroca_Installer.unitypackage」をUnityにドラッグ＆ドロップし、「Import」を押します
2. 確認画面で「Install」を押すと、最新版がダウンロードされて入ります（インターネット接続が必要です）
3. メニューの「Tools > いろか」からウィンドウを開きます

VCC・ALCOMをお使いの場合は、次のリポジトリを追加して、プロジェクトに「いろか」と「Non-Destructive Modular Framework」（NDMF）を追加することもできます（NDMFもこのリポジトリに載っています）。
https://yukkuri-aoba.github.io/Iroca/index.json

旧版（v0.1.0、旧名「VRC Avatar Color Changer」）をお使いだった場合は、Assets/VACCフォルダを削除してください。
```

### 権利メモ

アバターごとに扱いが違う。混ぜないこと。

- **HAOLAN（かなﾘぁさんち）… 再配布まで許可されたフリーアバター。ただしクレジット表記は必須。**
  3D レンダーも、テクスチャ（アトラス）の平面掲載も可。
  規約 V が「利用時のクレジット表記 必要です」・表記名は **かなリぁ**。
  掲載画像に HAOLAN を使う面（BOOTH 説明文・スライド）には必ずクレジット節を残すこと。
  スニーカーのヒーロー画像と、UI スクリーンショットのプレビュー領域はこれを使う。
- **Feina（Senna Studio）… 有償アバター。**
  3D レンダーの掲載は可。**テクスチャデータを平面画像として載せるのは不可。**
  （`ba-before.png` などのバンダナ素材はレンダーなので掲載自体は可。ただし現構成では未使用。）
