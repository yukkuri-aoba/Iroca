## 商品タイトル案

**【無料】Camereo — アバターテクスチャ色改変ツール**

---

## 概要文（本文）

```
Camereoは、独自の再配色エンジンを搭載した、
Unity上でアバターのテクスチャを直接色改変できるツールです。
PSD がない・レイヤーが統合済みのテクスチャでも、陰影や模様を保ったまま色を変えられます。
最適化(アトラス化)されたテクスチャでも使用可能です。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
　　　✅ こんなときに使えます
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

・購入したアバターの服や小物、あらゆるテクスチャの色を変えたい
・PSD や改変用データがついていない・もしくは欲しいレイヤーがない
・衣装の一部だけ色を変えたい

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
　　　🎨 主な機能
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【カラーゾーン】
色改変したい部分をスポイトで選ぶだけで、陰影・模様を保ったまま色が変わります。
複数ゾーンを重ねて使えます。順番をドラッグで変えるだけで優先度を制御できます。

【除外マスク（ブラシ）】
変えたくない部分をプレビュー上でブラシを使って直接塗るだけで保護できます。
全ゾーン共通と各ゾーン専用の 2 種類があります。

【プレビュー】
変更前後の比較・差分表示に対応。ピクセル単位まで拡大して細部を確認できます。

【プリセット】
設定（マスクも含む）をプリセットとして保存・読み込みできます。
JSON の書き出し・読み込みに対応しているので、設定をほかのプロジェクトやフレンドと共有することもできます。

【精度の高い再着色アルゴリズム】
知覚色空間（OkLab）をベースにしたアルゴリズムで、色相が変わっても自然な明度・陰影を保ちます。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
　　　📋 動作環境
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

・Unity 2022.3.22f1（VCC や VRCSDK とは現在依存していません）
・入力形式：PNG / JPG
・出力形式：PNG

・開発・パフォーマンステストに使用したPCの構成:
    CPU: AMD Ryzen 7 5700X
    RAM: 32GB
    GPU: NVIDIA GeForce RTX 2060 SUPER
    OS: Windows 11 Home 25H2


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
　　　📦 インストール方法
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. ダウンロードした zip を展開します
2. .unitypackage を Unity Editor にドラッグ＆ドロップします
3. Import をクリックします
4. Tools > Camereo でウィンドウを開けば準備完了です

詳しい使い方はツール同梱の MANUAL.md をご覧ください。
```
