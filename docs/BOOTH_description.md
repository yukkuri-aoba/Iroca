### 段落：使い方

```
1. いろかのウィンドウを開き、色を変えたいテクスチャを「テクスチャ」欄へドラッグします
2. 「スポイトで変えたい色を選ぶ」を押して、プレビュー上の変えたい色をクリックします
3. 「変更先カラー」で新しい色を選びます
4. 「自動調整」を押すと、影からハイライトまでが入るように範囲を合わせます（押さなくても色は変わります）
5. 「アバターに非破壊で登録」を押せば完了です。画像（PNG）として書き出すこともできます

はみ出したところや塗り残しは、プレビューを右クリックして「ここは塗らない」「ここも塗る」で直せます。細かいところはブラシでも塗れます。
同じ色がほかの場所にもあって、一か所だけ変えたいときは「この部分だけ塗る」を選びます。
服に描かれたファスナーや小さなロゴだけを外したいときは「小さめの部分で」、パーツ全体が取れないときは「大きめの部分で」から同じ操作を選べます。
```

### 段落：主な機能

```
・色は複数指定でき、パーツごとに別の色にできます
・右クリックでは、クリックした場所がどこまでのパーツかをAI（MobileSAM）が見分けます。AIの処理もPCの中だけで行うので、テクスチャが外部に送られることはありません
・テクスチャを使うメッシュが見つかれば、メッシュの形（UVの島）でも範囲を指定できます。色では分けられない、同じ色の別パーツも分けられます
・アバターへの登録は、NDMFを使った非破壊方式です。元のテクスチャとマテリアルはそのままで、再生やアップロードのときだけ色を変えたテクスチャに差し替わります。再生しなくても、シーン上のアバターで仕上がりを確認できます
・どのテクスチャを開けばいいか分からないときは、いろかのウィンドウを開いたままSceneでモデルの変えたい所をクリックすると開けます
・設定はプリセットとして保存でき、JSONで別のプロジェクトにも持っていけます
・AIエージェント（Claude Code・Cursorなど）から、MCP for Unityを通していろかを使えます。「この衣装を紺色にして」と頼むと、テクスチャの色を調べて色替えし、アバターに非破壊で登録します。仕上げはいろかのウィンドウで直せます
```

### 段落：苦手なテクスチャ

```
似た色があちこちにあるテクスチャや、グラデーションや強い光沢があるテクスチャは、一度では思いどおりの範囲にならないことがあります。右クリックの「ここも塗る」「ここは塗らない」やブラシで直してください。マニュアルの「困ったとき」にも対処法を載せています。
```

### 段落：動作環境

```
・Unity 2022.3（2022.3.22f1・Windowsで動作を確認しています）
・入力：PNG／JPG（PSDやTGAなども、Read/Writeを有効にすれば使えます）
・出力：PNG
・8192×8192までのテクスチャで確認しています。編集も書き出しも元の画像の解像度で行います（8Kの画像では数GBのメモリを使います。ウィンドウを閉じると手放します）。辺が8192を超える画像は、編集をインポート設定のMax Sizeの大きさで行います
・AIを使う機能（自動調整と、右クリックでの範囲の見分け）には、Unity Sentis 2.1.3（Unity 2022.3.11f1以降）とAIモデル（約44MB）が必要です。どちらもウィンドウ上部の案内から導入できます。Sentisを入れると、VRChat SDKも使うBurstとCollectionsも新しい版に上がります
・アバターへの登録にはNDMF 1.8以上2.0未満を使います。インストーラで導入した場合は一緒に入ります。NDMFがなくても、画像（PNG）の書き出しは使えます（NDMFがない、または対応していない版のときは、「Iroca Recolor」の付いたアバターのアップロードを止めて直し方を表示します）
```

## バリエーションと配布ファイル

| バリエーション名 | 価格 | 作品ファイル |
|---|---|---|
| 無料版 | ¥0 | `Iroca.zip` |
| 応援パック | ¥300 | `Iroca_応援パック.zip` |

- バリエーション名と zip の名前には版を入れない。インストーラは読み込んだ時点の最新版を入れるので、版を上げても差し替えなくてよい（作り方と、差し替えが要るときは `RELEASING.md` の「BOOTH の zip」）。
- 無料版の名前は 2026-10-19 に「Iroca_Ver0.2.0(Beta)」から「無料版」に変えた。応援パックの中身が無料版と同じことは、商品紹介文の一文で伝える（バリエーション名には書かない。ユーザー決定）。
- 応援パックの 2 つは、無料版の中身にお礼のメッセージ（`dev_safe/promo/応援パックを購入してくださった方へ.txt`）を足したもの。
- 2026-10-20、0.2.1 の公開と同時に、3 つとも 0.2.0 の配布 zip（`Iroca_v0.2.0.zip`）から上の名前の zip へ差し替えた（ユーザー決定。新しい README.txt に 0.2.1 の動きが書いてあるため）。
  BOOTH の「ファイルの追加・管理」は商品ごとに 1 つの一覧で、バリエーションごとにチェックで配るファイルを選ぶ。`Iroca_v0.2.0.zip` は消さずにチェックを外してある。
  一覧には各ファイルの DL 回数が出る（バリエーションの合計。`Iroca_v0.2.0.zip` は差し替え時点で 44）。
  アップロード欄には file 入力が無い（ドラッグ＆ドロップで受ける）ので、自動で入れるときは、ページに一時的な file 入力を作ってファイルを渡し、ドロップ欄へ drop イベントで落とす。
- いま BOOTH に置いている zip の SHA256（作り直した zip と同じなら差し替えは要らない）:
  - 無料版 `Iroca.zip`: `f44a3610b4569c80dd4a309b94af278c45845e54eaa680b6b195adfa5ed919c8`（GitHub の `Iroca_v0.3.0.zip` と同じ。0.3.0 でインストーラの NDMF の範囲に上限を付けたので差し替えた）

## 掲載画像

現行の掲載画像は 10 枚。1〜6 枚目はプライベート側の `dev_safe/promo/booth_new_lavender2/out/slide-1.png`〜`slide-6.png`（2026-10-17 に下書きの画像を差し替えた）。
中身と順番はそれまでの `booth_new_plain6` と同じで、デザインだけを変えた（薄紫の地、見出しは左上、右上に「いろか」、下に説明の帯、書体は Noto Sans JP）。
5 枚目（動作環境）は 2026-10-18 に文面を直した（「入出力」→「入力」に「書き出しは PNG」を添え、「Windows 10 / 11」→「Windows で動作確認」）。
表紙の文言は「好きな色の服を、Unity の中で／画像編集ソフトを使わずに、狙った色だけ変えられます。」。
デザインの決まりと、決めるまでの聞き取りは `dev_safe/promo/DESIGN.md` と `dev_safe/promo/booth_cover_trials/`。作り方は `make_lavender2.py` の先頭にある。

7〜10 枚目は 0.3.0 の公開（2026-10-25）で足した、0.2.1 と 0.3.0 の色の出方の比較（Rito_null のシャツ）。元はプライベート側の
`dev_safe/version_accuracy/2026-10-25_rito_color/sns/1_vivid.png`〜`4_texture.png`。Rito_null の規約はクレジット不要（あると嬉しい）なので、説明文のクレジットに載せた。

BOOTH の編集画面では、画像の追加と削除は「保存」を押さなくてもその場で反映される（削除のときに確認が出る）。
「画像を追加」はファイルを選ぶ窓を開くので、自動で入れるときは、ページの file 入力にファイルを直接渡す。

### 権利メモ

アバターごとに扱いが違う。混ぜないこと。

- **HAOLAN（かなﾘぁさんち）… 再配布まで許可されたフリーアバター。ただしクレジット表記は必須。**
  3D レンダーも、テクスチャ（アトラス）の平面掲載も可。
  規約 V が「利用時のクレジット表記 必要です」・表記名は **かなリぁ**。
  掲載画像に HAOLAN を使う面（BOOTH 説明文・スライド）には必ずクレジット節を残すこと。
  スニーカーのヒーロー画像と、UI スクリーンショットのプレビュー領域はこれを使う。
- **Feina（Senna Studio）… 有償アバター。**
  3D レンダーの掲載は可。**テクスチャデータを平面画像として載せるのは不可。**
  （`ba-before.png` などのバンダナ素材はレンダーなので掲載自体は可。ただし現構成では未使用。
  2026-07 の旧キット `docs/booth/images/` に入れた 4 枚は、ファイルを消した今も公開リポの履歴に残っている。）
