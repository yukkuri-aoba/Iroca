## 概要文（本文）

> 冒頭 3 行は検索一覧・シェア時のプレビューに出やすいので、フックを先頭に置いています。

```
「この衣装、色違いがあれば…」を、自分で作れる無料ツールです。
PSD がない統合済みテクスチャでも、スポイトで色を選ぶところから始められます。
陰影や模様はそのまま、色だけが変わります。

いろか / Iroca は、Unity 上でアバターのテクスチャを直接色改変できるエディタ拡張です。
独自の再配色エンジン（OkLab ベース）搭載。アトラス化済みテクスチャにも対応。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ こんなときに
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

・アバターや衣装の色を変えたいが PSD がない／欲しいレイヤーがない
・衣装の一部だけ色を変えたい
・アトラス化済みテクスチャを改変したい

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🎨 基本の流れは 3 ステップ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. テクスチャ（PNG / JPG）を読み込む
2. スポイトで「変えたい色」を選ぶ
3. 「変更先の色」を決めて PNG に書き出す

うまくいかなければ許容範囲とマスクで調整できます。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🧰 主な機能
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【カラーゾーン】
スポイトで色を選び変更先を設定。陰影・模様を保ったまま色が変わります。
ゾーンを複数重ねればパーツごとに別の色へ。優先度はドラッグで並替え。

【マスク（除外・含める）】
変えたくない部分（除外）と、必ず変えたい部分（含める）をプレビュー上で塗って指定。Ctrl+Z 対応。

【AI マスク提案（実験的）】
パーツを右クリックすると、AI が領域を推定してマスクに追加します。1 回で取れるのはつながった 1 領域なので、分かれたパーツは島ごとにクリック。

【プレビュー】
変更前後の比較・差分表示。ピクセル単位まで拡大して確認できます。

【プリセット】
設定（マスク含む）を保存・読み込み。JSON で他プロジェクトやフレンドと共有も可能。

【連続領域モード】
同じ色でもクリックした場所とつながった領域だけを選択。離れた別パーツは巻き込みません。

【自動調整】
スポイト位置を AI マスク提案で判定し、影からハイライトまでを覆うように許容範囲などを合わせます。
（Unity Sentis と AI モデル約 44 MB が必要。ウィンドウ上部の案内から導入できます）

【OkLab 再配色エンジン】
知覚色空間ベースで、色相を大きく変えても明度・陰影が自然に残ります。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
⚠ うまくいきにくいケース
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

・同じ色の別パーツが離れている → 連続領域モード or 除外/含めるマスク
・アトラス内に同色が散在 → パーツごとにスポイト＋含めるマスク
・光沢が強い／明部で色味が変わる塗り → 許容範囲を上げるか明部を再スポイト

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📋 動作環境
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

・Unity 2022.3.22f1（Windows で検証）
・VCC・VRChat SDK は不要（Unity 単体で動作）
・自動調整・AI マスク提案には Unity Sentis 2.1.3（Unity 2022.3.11f1 以降）と AI モデル（約 44 MB・初回ダウンロード）が必要
・入力：PNG / JPG（PSD・TGA なども Read/Write を有効にすれば可）　→　出力：PNG
・4096×4096 までのテクスチャで検証

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📦 インストール
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Iroca_Installer.unitypackage を Unity にドラッグ＆ドロップ → Import
2. 確認ダイアログで「Install」→ 最新版が自動でダウンロードされます（インターネット接続が必要）
3. Tools > いろか でウィンドウを開けば準備完了

VCC / ALCOM からも導入できます（リポジトリ：https://yukkuri-aoba.github.io/Iroca/index.json）。
旧版（v0.1.0、旧名 VRC Avatar Color Changer）を使っていた場合は、Assets/VACC フォルダを削除してください。
詳しい使い方はオンラインマニュアルをご覧ください：https://yukkuri-aoba.github.io/Iroca/manual/
```

### 権利メモ

アバターごとに扱いが違う。混ぜないこと。

- **HAOLAN（かなﾘぁさんち）… 再配布まで許可されたフリーアバター。ただしクレジット表記は必須。**
  3D レンダーも、テクスチャ（アトラス）の平面掲載も可。
  規約 V が「利用時のクレジット表記 必要です」・表記名は **かなリぁ**。
  掲載画像に HAOLAN を使う面（BOOTH 説明文・スライド）には必ずクレジット節を残すこと。
  スニーカーのヒーロー画像と、UI スクリーンショットのプレビュー領域はこれを使う。
- **Feina（Senna Studio）… 有償アバター。**
  3D レンダーの掲載は可。**テクスチャデータを平面画像として載せるのは不可。**
  （`ba-before.png` などのバンダナ素材はレンダーなので掲載自体は可。ただし現構成では未使用。）
