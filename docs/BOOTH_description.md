## 概要文（本文）

> 冒頭 3 行は検索一覧・シェア時のプレビューに出やすいので、フックを先頭に置いています。

```
「この衣装、色違いがあれば…」を、自分で作れる無料ツールです。
PSD がない統合済みテクスチャでも、スポイトで色を選ぶだけ。
陰影や模様はそのまま、色だけが変わります。

いろか / Iroca は、独自の再配色エンジンを搭載した、
Unity 上でアバターのテクスチャを直接色改変できるエディタ拡張です。
最適化（アトラス化）されたテクスチャにも使えます。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ こんなときに使えます
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

・購入したアバターや衣装、小物の色を変えたい
・PSD などの改変用データが付いていない／欲しいレイヤーがない
・衣装の一部だけ色を変えたい
・アトラス化（最適化）済みのテクスチャを改変したい

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🎨 使い方は 3 ステップ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. テクスチャ（PNG / JPG）を読み込む
2. スポイトで「変えたい色」を選ぶ
3. 「変更先の色」を決めて PNG に書き出す

Unity にインポートするだけで動きます。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🧰 主な機能
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【カラーゾーン】
スポイトで色を選び、変更先の色を設定するだけで、
陰影・模様を保ったまま色が変わります。
ゾーンを複数重ねれば、パーツごとに別の色へ変更できます
（優先度はドラッグで並べ替えるだけ）。

【除外マスク（ブラシ）】
変えたくない部分は、プレビュー上でブラシで塗るだけで保護できます。
全ゾーン共通・各ゾーン専用の 2 種類。Ctrl+Z の取り消しにも対応。

【プレビュー】
変更前後の比較・差分表示に対応。
ピクセル単位まで拡大して細部を確認できます。

【プリセット】
設定（マスク含む）をプリセットとして保存・読み込みできます。
JSON の書き出し・読み込みに対応しているので、
ほかのプロジェクトやフレンドと設定を共有できます。

【色が濁らない再着色エンジン】
知覚色空間（OkLab）ベースのアルゴリズムで、
色相を大きく変えても明度・陰影が自然に残ります。
```

## 掲載画像の並び（docs/booth/ のスライド）

デザインは、比較画像とUIを主役にした紺×白の情報デザイン。装飾フォント・放射背景・爆発形バッジは使わず、Noto Sans JPのウェイト、余白、細い罫線で情報の優先順位を作る。

1. `slide-1`（正方形 1280×1280 の表紙）… **メイン画像**。変化の実例と「いろか」を最優先で見せる。
2. `slide-2` PSDがなくても、色を変えられる。
3. `slide-3` 色を選んで、変更先を決める。（Before / After）
4. `slide-4` 色ごとに、変更範囲を分ける（実UIのスポイト箇所を注釈）
5. `slide-5` 変えたくない場所だけ、守る（実UIのブラシ箇所を注釈）
6. `slide-6` 仕上がりを確認してから書き出す（実UIの比較・差分タブを注釈）
7. `slide-7` 陰影の見え方を保ったまま、色を移す。（HSV vs OkLab、`tools/oklab_strip.py` の実計算値）
8. `slide-8` 導入から書き出しまで、4ステップ。

書き出し: `python docs/booth/tools/capture.py`（`slides.html` の 8 枚 → `out/`）。
スライド 4〜6 は Unity スクショを `docs/booth/images/` に置いて再実行すると自動で差し替わる（未配置の間はプレースホルダ表示）。
サムネ判読チェック: `python docs/booth/tools/thumbcheck.py out/slide-1.png`。

※権利メモ: バンダナの Before/After は Feina アバターの3Dレンダー（レンダー掲載は可）。Feina のテクスチャを平面画像としてそのまま載せるのは全スライドで禁止。アトラス見本は CSS モックで作成済み。
