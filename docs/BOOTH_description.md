## 概要文（本文）

> 冒頭 3 行は検索一覧・シェア時のプレビューに出やすいので、フックを先頭に置いています。

```
「この衣装、色違いがあれば…」を、自分で作れる無料ツールです。
PSD がない統合済みテクスチャでも、スポイトで色を選ぶだけ。
陰影や模様はそのまま、色だけが変わります。

いろか / Iroca は、独自の再配色エンジンを搭載した、
Unity 上でアバターのテクスチャを直接色改変できるエディタ拡張です。
最適化（アトラス化）されたテクスチャにも使えます。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ こんなときに使えます
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

・購入したアバターや衣装、小物の色を変えたい
・PSD などの改変用データが付いていない／欲しいレイヤーがない
・衣装の一部だけ色を変えたい
・アトラス化（最適化）済みのテクスチャを改変したい

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🎨 使い方は 3 ステップ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. テクスチャ（PNG / JPG）を読み込む
2. スポイトで「変えたい色」を選ぶ
3. 「変更先の色」を決めて PNG に書き出す

Unity にインポートするだけで動きます。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🧰 主な機能
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【カラーゾーン】
スポイトで色を選び、変更先の色を設定するだけで、
陰影・模様を保ったまま色が変わります。
ゾーンを複数重ねれば、パーツごとに別の色へ変更できます
（優先度はドラッグで並べ替えるだけ）。

【除外マスク（ブラシ）】
変えたくない部分は、プレビュー上でブラシで塗るだけで保護できます。
全ゾーン共通・各ゾーン専用の 2 種類。Ctrl+Z の取り消しにも対応。

【プレビュー】
変更前後の比較・差分表示に対応。
ピクセル単位まで拡大して細部を確認できます。

【プリセット】
設定（マスク含む）をプリセットとして保存・読み込みできます。
JSON の書き出し・読み込みに対応しているので、
ほかのプロジェクトやフレンドと設定を共有できます。

【連続領域モード】
同じ色でも、離れた場所にある別パーツは巻き込みません。
クリックした場所とつながっている領域だけを選びます。

【自動調整】
スポイトで 1 クリックするだけで、
暗い影の部分から明るいハイライトまでまとめて選択します。
許容範囲の数値を自分で調整する必要はありません。

【色が濁らない再着色エンジン】
知覚色空間（OkLab）ベースのアルゴリズムで、
色相を大きく変えても明度・陰影が自然に残ります。
```

## 掲載画像の並び（docs/booth/ のスライド）

アートディレクションは「色を、撮る」。原則は 3 つ。

1. **色を持つのは被写体だけ。** 背景・文字・UI はすべて無彩色に落とす。過去の POP 版は黄地と赤枠が被写体の色と喧嘩し、色替えツールなのに色が見えなくなった。
2. **装飾で美しくしようとしない。** 傾けた枠・ドロップシャドウ・袋文字・集中線・爆発バッジ・角丸は使わない。写真は矩形で大きく断ち落とす。
3. **文字は少なく、大きく。** BOOTH 一覧では約 150px に縮小される。

被写体はスニーカー。光沢・宝石・紐・縫い目があり、「色だけ変わって質感は残る」ことを最も強く証明できる。
（旧素材のバンダナはほぼ陰影のないベタ布で、この製品の最大の売りを何も証明できていなかった。）

1. `slide-1`（正方形 1280×1280 の表紙）… **メイン画像**。同一カメラ・同一ポーズの 2 枚を重ねて斜めにクリップし、1 足の靴の左半分が元の青・右半分が朱になる。分割線そのものが「色の境界」になる。
2. `slide-2` 陰影も、模様も、そのまま残る。（マクロ。質感が残っていることの証拠）
3. `slide-3` 好きな色に、何色でも。（8 色の色見本帳。**並ぶ色は全て製品が実際に出力した色**）
4. `slide-4` 色を選んで、変更先を決める。（実 UI）
5. `slide-5` 変えたくない場所は、守れる。（実 UI）
6. `slide-6` 書き出す前に、確かめられる。（実 UI）
7. `slide-7` 色相を変えても、濁らない。（HSV vs OkLab、`tools/oklab_strip.py` の実計算値）
8. `slide-8` 導入から書き出しまで、4ステップ。

### 素材の作り方

```
# 1. 色替えテクスチャを実 C# エンジンで量産（--autotune 付き = 実機の1クリックと同じ）
python dev_safe/scripts/build_promo_textures.py

# 2. Unity で撮影（dev_safe/unity_promo/PromoShot.cs / README.md を参照）
#    Tools > 販促撮影 > スタジオを構築 → 連番撮影
#    2560×1600（16:10）・背景透過・同一カメラ同一ポーズ
#    → docs/booth/images/ に hero-00-original.png … hero-08-sakura.png

# 3. スライドを撮影
python docs/booth/tools/capture.py
python docs/booth/tools/thumbcheck.py out/slide-1.png   # 150px で読めるか
```

**Scene ビューでスクショを撮らない。** 床グリッド・ギズモ・空のグラデーションが写り込み、デフォルトライティングでは陰影が出ない。陰影が出ない絵ではこの製品は何も証明できない。

画像が未配置の間はプレースホルダ表示になる。置いて再実行すれば自動で差し替わる。
